## 最短命的朝代不是秦朝是后汉

公元947年，原后晋大将刘知远趁契丹灭后晋后的权力真空，在太原称帝，国号汉。刘知远从起兵到称帝只用了不到一年，算是五代建国最快的皇帝。

但刘知远当皇帝不到一年就病死了。他十八岁的儿子刘承祐接班，就是后汉隐帝。年轻皇帝急于掌权，听信谗言，一口气杀了杨邠、史弘肇、王章三个托孤大臣，还下令去邺城杀枢密使郭威。

郭威被逼反了，带兵南下。刘承祐的亲兵在前线临阵倒戈，他逃跑时被自己的随从一刀砍死。从刘知远称帝到后汉灭亡，前后满打满算不到四年。比秦朝十五年、隋朝三十七年短得多。

后汉灭亡后，郭威建立后周。然后就是赵匡胤陈桥兵变建立北宋。可以说后汉这个短命王朝直接引爆了后周和北宋的连锁反应。

四年时间，两个皇帝，一个病死一个被砍死。这就是中国历史上最短命的统一王朝。
