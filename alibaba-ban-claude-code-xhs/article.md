阿里全面禁用Claude Code
今天是 AI 编程圈的大新闻：阿里内部通知全面禁用 Claude Code。

原因很硬核——Claude Code 被曝存在植入后门的风险，阿里直接将其列入高风险软件名单。

7月10日起全员卸载，Anthropic 全线产品（Sonnet、Opus、Fable、Claude Code）全部被禁。内部推荐使用自研 Qoder 替代。

三个关键影响：

1. 代码助手安全成红线
能植入后门的编程工具，企业谁敢用？阿里的动作，其他大厂大概率跟进。企业级 AI 工具安全审查从加分项变成必选项。

2. 国产替代加速
从芯片到模型到工具链，阿里这波是"自主可控"的又一刀。Qoder 作为阿里云编程助手，将承接大量内部流量。

3. 开发者怎么办
阿里系员工：赶紧切换工具链到 Qoder。
外部开发者：评估自己用 Claude Code 的风险敞口。

AI 工具好用很重要，安全更重要。
