百年孤独：马乌里肖·巴比洛尼亚（黄色蝴蝶）

马乌里肖·巴比洛尼亚，《百年孤独》里有黄色蝴蝶的男人。

他是香蕉公司的技工，身上总沾着机油和汗味。他爱上了梅梅——费尔南达的女儿。两人的爱情从一开始就不被允许。费尔南达怎么能接受女儿跟一个修机器的交往？

但爱情有它自己的办法。马乌里肖学会了掀开屋顶的瓦片，每晚溜进浴室跟梅梅约会。他去到哪里，黄蝴蝶就跟到哪里。马尔克斯写道：他出现的时候总是跟着一群黄蝴蝶，像一道移动的光。那蝴蝶多得能把人眼睛迷住，让人看不清他的脸。

黄蝴蝶是马乌里肖的标志，也是马尔克斯写得最浪漫的意象之一。马乌里肖来的时候蝴蝶就来了，他走了蝴蝶也走了。梅梅看到黄蝴蝶就知道他在附近。这是他们之间的秘密信使。

费尔南达发现了秘密。她叫来守卫埋伏在屋顶。那天晚上马乌里肖刚掀开瓦片，子弹就打穿了他的脊椎。他摔下来，从此瘫痪不起。黄蝴蝶也消失了。

马乌里肖孤独地活了很久。他瘫痪在床，动弹不得，唯一让他撑下去的是对梅梅的思念。他每天盯着天花板，想着她。他死的时候，没有蝴蝶。

而在千里之外的修道院里，梅梅翻了个身。她的后半生，一个字都没说过。
