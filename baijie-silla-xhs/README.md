百济、新罗与南朝——跨海朋友圈

南北朝时期，朝鲜半岛也有三国——高句丽、百济、新罗。其中百济和新罗，与南朝保持了长期密切的跨海交往。

百济是南朝最铁的朋友。公元372年首次遣使到东晋。此后三百多年，百济使团走海路来到建康，带来朝鲜的药材、纸张、战马。南朝回赠了儒家经典、佛教典籍、乐器和工匠。百济贵族以穿南朝衣冠为荣。

新罗和南朝的关系稍晚。公元521年，新罗使团到梁朝，带来了金器、人参和美女。梁武帝赐给新罗佛经和佛像。新罗从此引入佛教。

这些跨海联系不只是外交礼仪。百济和新罗通过南朝引进了汉字、佛教、儒家制度、医学、天文历法，奠定了朝鲜半岛文化的基础。海上的友谊，比陆地上的战争持久多了。
