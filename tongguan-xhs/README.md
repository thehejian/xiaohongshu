## 潼关

位于陕西最东端，黄河大拐弯处，是明清以来关中最重要的东大门。它取代了函谷关的地位，成为历代兵家必争之地。

### 地理险要

潼关的险要在于它的位置——南靠秦岭、北临黄河、黄河对岸是山西的中条山，关城夹在山水之间只有一条窄路通过。

### 历史战役

**曹马大战**：曹操与马超在此鏖战，曹操割须弃袍差点送命。

**安史之乱**：哥舒翰率二十万唐军守潼关，被唐玄宗逼着出战导致大败，潼关失守，长安沦陷。

**黄巢起义**：起义军攻破潼关，唐朝末路自此开始。

**明代巅峰**：潼关达到顶峰，成为全国最大的军事要塞之一。

**抗日战争**：日军隔黄河炮击潼关多年，但始终没能突破潼关防线。
