百年孤独：开头与结尾

《百年孤独》的开头和结尾，写了布恩迪亚家族的整个命运。一字不差。

开头第一句："多年以后，面对行刑队，奥雷里亚诺·布恩迪亚上校将会回想起父亲带他去见识冰块的那个遥远的下午。"

这一句话里包含了三个时间：多年以后（未来），面对行刑队（当下），那个遥远的下午（过去）。马尔克斯用一个句子把过去、现在、未来叠在一起。布恩迪亚家族的宿命感，从第一个字就开始了。

见识冰块——冰块是吉普赛人梅尔基亚德斯带来的。何塞·阿尔卡蒂奥·布恩迪亚花了不少钱，让儿子摸到了冰块。他说："这是我们时代最伟大的发明。"一个原始热带小镇里的人第一次见到冰，以为是钻石。可笑吗？但这是布恩迪亚家族探索精神的起点——他们相信奇迹，愿意为奇迹付出一切。

结尾最后一句："注定要一百年孤独的家族不会有第二次机会在大地上出现。"

奥雷里亚诺·巴比洛尼亚读完了羊皮纸，看到了自己的命运。孩子被蚂蚁吃掉，姨妈产后大出血而死，他被飓风吹走。整个马孔多在地球上消失。

这句结尾对应了开头——头尾一百年。开头的人相信奇迹，结尾的人发现一切早已注定。第一代摸到了冰块，最后一代被飓风吹走。中间发生的一切，不过是把羊皮纸上写的东西演完。

马尔克斯说，他花了很多年才找到这个开头。找到以后就知道这本书写完了——因为开头包含了结尾，结尾呼应了开头。

这就是为什么《百年孤独》不用读第二遍。第一遍就够了。因为无论你读多少遍，结局都不会变。
