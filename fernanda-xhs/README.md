百年孤独角色卡：费尔南达

费尔南达·德尔·卡皮奥，《百年孤独》里最格格不入的人。

她从小被家人当作女王培养——他们家曾经很富有，后来败落了，但父母倾家荡产也要让她活在"你将来要当马达加斯加女王"的幻觉里。她穿着缀满珍珠的裙子长大，会用拉丁文祈祷，不知道超市多少钱一斤。

她嫁给了奥雷里亚诺第二。婚礼那天她坐着一辆装饰得像灵车的马车来到马孔多，带来了全套银器、床单和一只黄金便盆。奥雷里亚诺第二第一眼就后悔了——太讲究了，跟他家格格不入。

婚后她努力把布恩迪亚家变成她理想中的宫殿。每天戴黑纱做弥撒，餐前必须祈祷，地板上不能有泥巴。但没人配合她。奥雷里亚诺第二很快就跑回情妇家吃饭了。三个孩子也不听她的。

她这辈子最残酷的两个决定：一是把大儿子送进神学院（他后来成了神父，母亲死后却回了马孔多，被四个年轻人谋财害命，扔进了池塘）；二是发现女儿梅梅和技工马乌里肖的地下恋情后，叫来守卫开枪打死了他。梅梅从此再也不说话了，被送进修道院直到老死。

费尔南达一个人守着空荡荡的大房子，每天穿着过时的女王裙子在家里走来走去。香蕉公司倒闭后马孔多破败了，她还坚持不降低生活标准——宁可挨饿也要保持体面。

她死在那个大房子里，身边没人。最后一个布恩迪亚回家时发现了她的尸体。到死她都没明白，自己怎么就从"马达加斯加女王"变成了马孔多的笑柄。
