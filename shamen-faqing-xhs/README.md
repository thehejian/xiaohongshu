沙门法庆起义——北魏的宗教战争

公元515年，北魏冀州爆发了一场特殊的农民起义——沙门法庆起义。说它特殊，因为领导起义的是一个和尚。

法庆宣称"新佛出世，除去旧魔"。他主张杀人才能解脱——杀一人为一住菩萨，杀十人为十住菩萨。他烧寺院、杀僧侣、劫官府。起义军规模迅速膨胀到五万多人。法庆自称"大乘"，他的军队穿着黄衣，所过之处血流成河。

北魏朝廷派元遥率军十万镇压。法庆在战斗中阵亡，起义被血腥镇压，牵连者达数万。这场起义让北魏朝廷意识到宗教问题的严重性。此后北魏开始限制寺院经济和僧侣特权，也为后来的太武帝灭佛埋下了伏笔。

法庆起义虽然失败，但它揭示了一个真相：当宗教和政治混在一起，当信仰变成暴力工具，造成的破坏比任何战争都不小。
