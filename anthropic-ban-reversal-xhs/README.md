# Anthropic封禁大反转

## 事件时间线

**6月9日** — Anthropic发布Fable 5，号称史上最强模型。319页系统说明书被扒出隐藏机制：API静默检测蒸馏行为，发现即降级到Opus 4.8。

**6月9-10日** — 社区连夜AB测试验证，24小时内引爆全球讨论。核心争议：不是不让限制，是凭什么偷偷来？

**6月11日** — Anthropic道歉撤销隐蔽降智政策，改为可见降级通知。

**6月12日** — 美国商务部以国家安全为由下令禁止外国人访问Fable 5/Mythos 5。Anthropic被迫全球下架。

**6月14日** — David Sacks曝光Anthropic CEO拒绝修复越狱漏洞。大股东亚马逊反手向白宫举报。
