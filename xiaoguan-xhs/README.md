## 萧关

关中四关中的北关，位于今宁夏固原，是防御北方游牧民族的第一道防线。

### 历史地位

秦朝和汉朝时期，匈奴从河套地区南下进攻关中，萧关是必经之路。汉代在萧关一带修筑长城，屯驻重兵。汉武帝多次出巡萧关，视察边防。萧关是中原王朝与草原帝国对峙的最前线。

### 文学意象

唐朝诗人王维写下"萧关逢候骑，都护在燕然"，让萧关名垂诗史。诗中描写了边塞的辽阔苍茫——萧关之外就是大漠草原。

### 衰落

萧关在宋代以后战略地位下降。因为中原王朝的疆域北移，防线推进到了宁夏平原和河套地区。萧关从边境变成了内地。

### 遗址

今天的萧关遗址位于宁夏固原市，黄土残墙，大漠孤烟。它见证了汉唐盛世与游牧民族千年对抗，是北方边防最古老的见证者之一。
