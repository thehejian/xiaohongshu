昭陵六骏-什伐赤：从西域来的汗血宝马

什伐赤是一匹真正的汗血宝马。"什伐"是突厥语"赤色"的意思，所以什伐赤翻译过来就是"大红马"。简单直接，霸气外露。

这匹马是正宗的西域大宛马种，汉武帝当年派李广利率数万大军征大宛，为的就是这种马。一千年后，它出现在李世民的战场上。

虎牢关之战，什伐赤驮着李世民在万军阵中来回冲杀。它的前后身共中五箭，前胸四箭、背后一箭。但和别的马不一样——什伐赤中箭之后反而更猛了。它像是被激怒了一样，嘶鸣着冲向敌阵最深处。

李世民自己也受了轻伤。什伐赤带着伤和血，硬是驮着他坚持到了最后。战斗结束后，李世民发现什伐赤的汗是红色的——那不是汗血马传说中的"汗血"，而是它流的血和汗水混在一起。马身上五个箭洞都在往外渗血。

唐朝人有一句诗："朱汗骋足，青旌凯归。"红色的汗血宝马奋力奔跑，打着青色旗帜凯旋。说的就是什伐赤。

什伐赤的浮雕最能体现西域战马的特点——身材高大，肌肉饱满，脖子粗壮。一看就不是中原本土的马种。

当年昭陵六骏的浮雕是着色的，什伐赤在当年应该是红色的。可惜今天看到的是灰白的石头。如果能还原出唐代的色彩，一定能看到一匹鲜红如火的战马。
