## 武关

关中四关中的南关，位于今陕西丹凤，是走南阳盆地进入关中的必经之路。

### 战略意义

武关守卫着关中平原的南大门。从南阳盆地出发，经过武关就可以直抵蓝田、威胁长安。相比函谷关的天险，武关更容易被攻破——历史上几次关中的陷落，敌人都是走武关。

### 著名事件

**诱捕楚怀王**：秦国在武关设宴诱捕楚怀王。秦昭王写信请楚怀王到武关会盟，楚怀王一到就被秦军扣押，最后死在秦国。楚国从此一蹶不振。

**刘邦入秦**：刘邦灭秦走武关。他避开函谷关的秦军主力，绕道南阳翻越武关，一举攻入关中，秦王子婴出降。

### 文化意义

武关也是一条文化通道。历代文人过武关留下了大量诗篇。武关路上，马蹄声中，是商於古道的千年回响。
