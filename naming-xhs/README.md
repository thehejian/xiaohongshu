百年孤独：布恩迪亚家族的命名密码

布恩迪亚家整整七代人，来来回回就用两个名字：何塞·阿尔卡蒂奥和奥雷里亚诺。马尔克斯用名字划分了性格和命运。

叫何塞·阿尔卡蒂奥的：体型巨大，力大无穷，冲动暴躁，敢爱敢恨。第一代人何塞·阿尔卡蒂奥·布恩迪亚被科学逼疯绑在树上；大儿子何塞·阿尔卡蒂奥跟吉普赛人跑了又回来，被神秘枪杀；何塞·阿尔卡蒂奥第二经历了香蕉公司大屠杀；第五代的何塞·阿尔卡蒂奥当了神父又回来挥霍黄金。这四个人的共性：冲动、固执、会死在非命。

叫奥雷里亚诺的：瘦小，内向，聪明，闷骚，有预言能力。奥雷里亚诺·布恩迪亚上校打了半辈子仗；奥雷里亚诺·何塞跟姑妈乱伦被枪杀；奥雷里亚诺第二年轻时纵欲老年痛改前非；最后的奥雷里亚诺·巴比洛尼亚破译了羊皮纸，终结了整个家族。他们的共性：沉默、专注、心里装着秘密。

乌尔苏拉总结过：阿尔卡蒂奥们都是战士，但他们的命运指向毁灭；奥雷里亚诺们眼光独到，但走向孤僻。

马尔克斯用名字直接告诉读者——这是一个循环。同样的名字，同样的性格，同样的命运。所以当最后一个布恩迪亚出生时，乌尔苏拉说千万别叫他奥雷里亚诺或何塞·阿尔卡蒂奥——叫别的吧。但最后还是没躲过。猪尾巴的孩子，没有名字，被蚂蚁吃掉了。
