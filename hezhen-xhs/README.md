贺珍——大顺军的"重归大明"

1645年李自成在九宫山被杀，大顺军群龙无首。将领贺珍做了一个惊人决定——率部"重归大明"。

贺珍召集部下说："闯王已死，清军马上就来。我们是和清军拼到底，还是回到明朝那边去？"部下一致同意打清军回大明。他率五万人南下联络南明隆武朝廷，被封为"定武伯"，奉命北上收复陕西。

部队换上明朝旗号从汉中进攻西安，攻占不少地方。但南明援军迟迟不到，孤军奋战最终被清军击败。退入川陕交界大山中坚持十多年。1662年南明最后一个皇帝被杀后，贺珍解散部队隐居山中。

贺珍的故事不显眼——没有胜利也没有传奇。但他代表了大厦将倾时，仍然选择站在自己认为对的那一边的人。大顺军可以"重归大明"，比很多自诩忠臣的人更有骨气。
