百年孤独角色卡：梅尔基亚德斯

梅尔基亚德斯，《百年孤独》里死过两次又活过来的吉普赛人。

他每年三月来一次马孔多，带来的东西让何塞·阿尔卡蒂奥·布恩迪亚发疯：磁铁说可以吸出地下的黄金，放大镜说可以打造太阳武器，炼金术说可以把水银变成金子。每一样都让老布恩迪亚倾家荡产去试，每一样都失败了——但老布恩迪亚不在乎，他享受的是探索本身。

梅尔基亚德斯第一次死是在马孔多，死于热病。他的葬礼很隆重，布恩迪亚家为他戴孝。但过了几年他又回来了——因为"受不了死亡的无聊"。他满头白发，牙齿掉光，谁都不认识了，但他记得老布恩迪亚。两个老朋友在栗树下聊天，他教布恩迪亚念一种没人能懂的语言。

他后来搬进了布恩迪亚家，住在一个小房间里，用梵文写羊皮纸手稿。他死的时候没有葬礼，尸体直接被放进了房间，锁上门。从此这间屋子成了布恩迪亚家族最神秘的角落。

他死了以后一直在那个房间里。后来的奥雷里亚诺（双胞胎中的哥哥）躲进去跟他说话。最后一代奥雷里亚诺·巴比洛尼亚在这个房间里待了十几年，终于破译了那些羊皮纸。

羊皮纸上写的是整个布恩迪亚家族的历史——从第一个人被绑在树上，到最后一个人被蚂蚁吃掉。一字不差。

谁写的？梅尔基亚德斯。一个死了两次的吉普赛人，预言了这一切。
