慕容恪——十六国的战神天花板

十六国名将众多，但公认的战神天花板，是前燕的慕容恪。

慕容恪十五岁开始领兵打仗，一生未尝败绩。他攻灭冉魏，在廉台与冉闵决战，用铁锁连马组成连环阵，十战十败引诱冉闵深入，最后一举歼灭。他发明的"连环马"战术，用铁链把战马连成排冲锋，正面冲击力无敌。

但慕容恪不只是一个战将。他还是理性的政治家。慕容儁想迁都邺城，他劝阻；想灭东晋，他分析利弊让其放弃。他是前燕真正的定海神针。慕容儁临死时说："我弟弟慕容恪才最适合当皇帝。"但慕容恪坚决推辞，继续辅佐幼主。

慕容恪死时五十三岁。他一死，前燕立刻内斗，不到十年就被前秦灭了。慕容垂后来说："我哥慕容恪才真正配得上战神称号。"
