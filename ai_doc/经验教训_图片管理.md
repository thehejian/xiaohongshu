# 经验教训：图片管理与 LangGraph 流程

## 问题背景
2026-10-07，将小红书图片从项目目录移动到 mac_share 备份目录，导致 LangGraph 流程无法正常运行。

## 影响分析

### 1. LangGraph 流程中断原因
- **gen_fixed.py / gen_one.py**：从 `image-cards/topic-XXX/` 目录读取图片
- **verify_images 节点**：检查 `*.png` 文件是否存在并验证 PNG 格式
- 图片被移走后，生图脚本找不到文件，流程卡死

### 2. 受影响的节点
```
write_prompts → gen_images → verify_images → create_feishu
                           ↑
                    图片不存在时失败
```

### 3. 具体报错
```
RuntimeError: gen_fixed.py 失败(rc=0), 缺失=['01-cover.png', '02-cover.png', '03-cover.png']
```

## 解决方案

### 方案 A：生成后自动备份（推荐）
修改 `gen_fixed.py`，在生图完成后自动复制到备份目录。

```python
# 在 gen_fixed.py 末尾添加
import shutil
backup_dir = Path("/Volumes/mac_share/007-照片/小红书图片备份") / topic_name
backup_dir.mkdir(exist_ok=True)
for img in Path(".").glob("*.png"):
    shutil.copy2(img, backup_dir / img.name)
```

### 方案 B：一键恢复脚本
创建 `restore.py`，从备份恢复图片。

```python
# langgraph/xhs_graph/restore.py
from pathlib import Path
import shutil

BACKUP_ROOT = Path("/Volumes/mac_share/007-照片/小红书图片备份")
CARDS_ROOT = Path("/Users/mac/.qclaw/workspace/002-AIagent/03-opencode/003-Twitter/image-cards")

def restore_topic(topic_no: int) -> dict:
    backup_dir = BACKUP_ROOT / f"topic-{topic_no}"
    target_dir = CARDS_ROOT / f"topic-{topic_no}"
    target_dir.mkdir(parents=True, exist_ok=True)
    
    copied = 0
    for png in backup_dir.glob("*.png"):
        shutil.copy2(png, target_dir / png.name)
        copied += 1
    return {"success": True, "copied": copied}
```

### 新增图片时
1. 运行 langgraph 生图
2. 生图完成后，立即备份：
   ```bash

   # 或手动复制
   cp -r image-cards/topic-XXX/*.png "/Volumes/mac_share/007-照片/小红书图片备份/topic-XXX/"
   ```

### 定期备份
```bash
#!/bin/bash
# backup_xhs_images.sh
BACKUP_DIR="/Volumes/mac_share/007-照片/小红书图片备份"
SOURCE_DIR="/Users/mac/.qclaw/workspace/002-AIagent/03-opencode/003-Twitter/image-cards"

for dir in $SOURCE_DIR/topic-*/; do
    topic=$(basename "$dir")
    mkdir -p "$BACKUP_DIR/$topic"
    cp "$dir"*.png "$BACKUP_DIR/$topic/" 2>/dev/null
done

echo "Backup completed: $(date)"
```

## 教训总结

1. **不要随意移动已使用的资源**：LangGraph 流程依赖相对路径，移动文件会导致流程中断
2. **备份前确认依赖**：移动图片前，确认生图脚本是否会重新生成
3. **建立备份机制**：大型媒体文件应定期备份到外部存储
4. **记录路径变更**：路径变更必须记录，避免后续使用混乱

## 快速恢复命令

如果图片丢失，执行：
```bash
# 恢复单个 topic
python3 -c "
from pathlib import Path
import shutil
backup = Path('/Volumes/mac_share/007-照片/小红书图片备份/topic-XXX')
target = Path('image-cards/topic-XXX')
target.mkdir(parents=True, exist_ok=True)
for png in backup.glob('*.png'):
    shutil.copy2(png, target / png.name)
print('Restored')
"

# 批量恢复所有 topic
for dir in "/Volumes/mac_share/007-照片/小红书图片备份"/topic-*/; do
    topic=$(basename "$dir")
    mkdir -p "image-cards/$topic"
    cp "$dir"*.png "image-cards/$topic/"
done
```
