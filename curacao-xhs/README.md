德国7:1库拉索——世界杯历史上最离谱的对决

今天，2026年6月15日，美加墨世界杯E组首轮，德国7:1击败了库拉索。这不是预选赛，是世界杯正赛。

库拉索，15万人口，加勒比海一个小岛。今天是他们国家历史上第一次参加世界杯决赛圈。

2010年之前，库拉索叫荷属安第列斯。那年安第列斯解散了，库拉索变成了荷兰王国下的独立构成国——有自己的国旗、足球队。但没有FIFA席位。

2010年12月，库拉索正式加入国际足联。2024年，他们第一次拿到世界杯预选赛参赛资格。然后——他们真的做到了。小组出线，历史性闯入2026美加墨世界杯。

15万人的国家，第一次站上世界杯舞台。

库拉索队里一半球员出生在荷兰，从小在阿姆斯特丹青训系统长大。他们不是职业球员，是牙医、老师、快递员。为了穿国家队球衣，他们自己掏钱飞回来集训。

他们是纯正的荷属加勒比黑人血统——非裔克里奥尔人。蓝色球衣是他们唯一拥有的国旗。

德国队1小时内灌了5球。库拉索扳回一球——那是他们世界杯历史上的第一个进球。全场沸腾了。

最终7:1。德国队庆祝。库拉索球员坐在草地上哭了。

但整个加勒比海都在说：下次，我们会更强。

世界杯第一次有库拉索的名字，这就是意义。
