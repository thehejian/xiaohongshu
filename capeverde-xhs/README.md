佛得角——非洲最不像非洲的国家

佛得角，非洲西海岸外560公里，15个火山岛，56万人。首都普拉亚。葡萄牙语国家。Cesária Évora的故乡。

这里不像传统非洲——白人游客比黑人还多，葡萄牙风格的彩色房子，克里奥尔语。1456年葡萄牙人发现时无人居住，后来成为奴隶贸易中转站。1975年独立后成了非洲最稳定的民主国家之一。

最神奇的是Morna音乐——被称为非洲的蓝调。Cesária Évora光着脚把Morna唱到了全世界。

佛得角人常说"No Stress"。岛上节奏慢到忘掉手机。火山、沙漠、海滩、绿洲一个岛全齐。

2007年被联合国认定为"中等收入国家"——没有石油没有矿产，靠旅游和服务业。
