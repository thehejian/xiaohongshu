## 大散关

关中四关中的西关，位于今陕西宝鸡，是扼守陈仓道进入关中的咽喉。

### 历史地位

大散关的战略价值在三国时期达到顶峰。诸葛亮五次北伐，每一次都从大散关附近的陈仓道出兵。但大散关太险了，他始终没能攻破。最后诸葛亮积劳成疾，病逝五丈原。

### 文学意象

南宋时大散关成为宋金边境的西起点。陆游在此写下"楼船夜雪瓜洲渡，铁马秋风大散关"的名句。大散关以北是沦陷的土地。

### 古蜀道

大散关也是古蜀道的重要组成部分。从关中到四川，大散关是陈仓道和褒斜道的西端分岔点。无数军队和商旅从这里进出秦岭南北。

### 遗址

大散关的遗址在今宝鸡市南的秦岭山脊上，关城早已倾圮，但山势依旧险峻。站在大散关的遗址上，还能感受到"铁马秋风"的苍凉。
