## 函谷关

中国历史上最古老的雄关之一，位于今天河南灵宝，是关中平原的东大门。

### 历史地位

建于战国时期，秦国依靠函谷关抵御六国联军。"一夫当关，万夫莫开"说的就是这里。六国合纵攻秦，每次打到函谷关就打不动了。

### 著名事件

**老子著《道德经》**：老子西出函谷关时，关令尹喜请他留下著作，老子一气呵成写了五千言。

**孟尝君鸡鸣狗盗**：孟尝君被秦国扣留，靠着门客装鸡叫骗开关门才逃出去。

### 衰落

函谷关的战略地位在东汉后被潼关取代。因为黄河河道变迁，函谷关所在的峡谷失去了军事价值。但它的名气和历史地位永远无法被替代。
