凉州——乱世中的文化绿洲

五胡十六国，中原血流成河。但在西北的凉州，却有一片文化的绿洲。

凉州的核心在武威和敦煌。张轨建立前凉后，大量中原士人为躲避战乱逃到这里。他们把汉魏典籍、儒学传统带到了凉州。敦煌张氏世代传经，武威段氏精研礼乐。前凉立国七十六年，是十六国中最长寿的政权。

凉州还有一个特殊地位：西域商路的起点。敦煌是丝绸之路的咽喉，武威是商队的中转站。这里的商人会说粟特语、梵语、汉语，货栈里摆满了西域的香料、宝石、佛经。鸠摩罗什的翻译事业，如果没有凉州商路带来的梵文典籍，根本不可能完成。

五凉政权虽各有兴亡，但文化传承从未中断。魏孝文帝改革时，很多礼乐制度就是从凉州找回的。隋唐的宫廷音乐中，凉州乐是最重要的组成部分。可以说，没有凉州这片文化绿洲，就没有后来隋唐盛世的文脉根基。
