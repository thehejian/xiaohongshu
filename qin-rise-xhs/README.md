# 秦人六世一统天下🔥

战国七雄卷到飞起，最后却被西方来的秦人一锅端了——凭什么？

## ① 秦人发迹：从养马到建国

秦人的始祖非子是周孝王的养马官，因为养马养得好，被封在秦地（今甘肃天水）。西周灭亡时，秦襄公率兵勤王护送周平王东迁，被正式封为诸侯，秦国由此诞生。

## ② 迁都史：九迁定鼎

秦国的迁都史就是一部东进史：
- **西陲**（甘肃礼县）→ 秦邑 → **汧渭之会**（陕西眉县）→ 平阳 → **雍城**（陕西凤翔）→ 泾阳 → **栎阳**（西安阎良）→ **咸阳**

每一步都向东推进，从西陲边陲一步步走到关中核心。

## ③ 变法图强：商鞅变法

秦孝公任用商鞅变法，废井田、开阡陌、推行军功爵制，秦国从"蛮夷"变成"战争机器"。六国开始真正害怕秦国。

## ④ 奋六世之余烈

从秦孝公到秦王嬴政，连续六代（孝公→惠文王→武王→昭襄王→孝文王→庄襄王），代代都是明君或强君，这在世界历史上绝无仅有。

## ⑤ 吞并六国

公元前230-221年，秦王嬴政十年之内横扫六国：韩、赵、魏、楚、燕、齐，完成统一。书同文、车同轨、行同伦，中国历史上第一个大一统王朝诞生。
