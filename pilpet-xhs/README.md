百年孤独角色卡：庇拉尔·特尔内拉和佩特拉·科特斯

庇拉尔·特尔内拉和佩特拉·科特斯，《百年孤独》里两个让布恩迪亚男人离不开的女人。

先说庇拉尔。她是个靠算卦为生的女人，布恩迪亚家两代人的血脉都来自她：她跟大何塞·阿尔卡蒂奥生下了阿尔卡蒂奥，又跟奥雷里亚诺上校生下了奥雷里亚诺·何塞。她从不纠缠男人，也从不进布恩迪亚家的大门——她知道自己只是过客。但布恩迪亚家族后来的延续，全靠她这两个孩子。她活得很长很长，最后在马孔多开了家妓院，直到一百多岁才在一张吊床上安静离开。

再说佩特拉·科特斯。她是奥雷里亚诺第二的情妇，跟费尔南达是正反两面。费尔南达冷得像块冰，佩特拉热得像团火。她和奥雷里亚诺第二的爱情有个奇异的魔力：只要他们两个在一起，家里的牲口就疯狂繁殖，牛生双胎，鸡每天下两个蛋，钱多到花不完。但奥雷里亚诺第二每次回费尔南达身边，魔力就消失，牲口就死光。

佩特拉是个爽快人。布恩迪亚家破败后，她靠卖彩票养活了自己，也暗中接济费尔南达——她情敌——因为那是奥雷里亚诺第二的家人。奥雷里亚诺第二死后，她一个人住着，继续卖彩票，直到老去。

两个女人，一个给布恩迪亚家续了血脉，一个给布恩迪亚家带来了财富。她们都没进布恩迪亚家的门，但布恩迪亚家欠她们最多。
