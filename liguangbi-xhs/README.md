# 李光弼到底有没有反心

李光弼（708—764），营州柳城（今辽宁朝阳）人，契丹族，唐朝名将，与郭子仪并称"李郭"，为平定安史之乱的核心将领。

## 核心争议

李光弼晚年因「徐州事件」被质疑有异心。763年，朝廷召其入朝，他走到半路听说宦官程元振进谗言，立刻退回徐州，再不敢入长安。次年病重去世。

## 分析与解读

### 支持"无反心"的证据
- 战功卓著，安史之乱中以少胜多，太原之战、河阳之战皆是经典
- 临终遗言："吾在军中，不敢避死，但恐死不足塞责耳"——至死自省
- 退回徐州是恐惧而非反意：当时来瑱被冤杀，仆固怀恩被逼反，人人自危

### 支持"有疑点"的侧面
- 契丹人身份在唐朝始终不被完全信任
- 徐州抗命不遵是事实
- 与郭子仪相比，缺少"功成身退"的政治智慧

## 结论

历史争议的核心不在于李光弼是否真有反心，而在于一个功勋卓著的异族将领，在宦官专权的晚唐环境中，如何自处。
