# Analysis

## Type
Institutional overview

## Key Points
- Four pillars of Qin unification
- 书同文: unified script (xiaozhuan)
- 车同轨: unified track width
- 统一度量衡: unified weights and measures
- 行同伦: unified social norms
- Together they created Chinese civilization framework
- Outlasted the Qin dynasty
