# 郑希景气度投资框架 Skill

让AI学会景气度投资——把易方达郑希的公开投资方法论做成AI Agent Skill。

## 核心价值

把模糊的热度变成有逻辑、有证据、有风险边界的研究方向。

### 它能做什么

- **景气方向扫描**: 给一个主题（AI算力、半导体、新能源…），AI自动拆产业链、找通胀层、筛ROE弹性标的
- **单股挑战**: 分析一只股票在产业链的位置、ROE弹性类型、什么能证伪判断
- **候选比较**: 按ROE弹性、证据强度、风险排序多个标的
- **方法学习**: 从系统变化到产业链到通胀到ROE弹性，一步步建立投资框架

### 核心理念

1. **景气度投资，非成长股投资** — 投的是产业景气周期，找"通胀"（供需错配导致的价格上行）
2. **复利 = 周期拼接** — 不持有"伟大公司"等复利，逐次拼接景气周期
3. **最高原则：客观** — 每天区分"愿望"和"判断"

### 四步研究流程

1. **全球图谱定景气方向**: 识别系统变化 → 画产业链图谱 → 找通胀层
2. **选ROE低的公司**: 行业压制型(A类) + 前瞻研发型(B类)
3. **流动性筛选 + 六维跟踪**: 竞争对手、上游供应、下游客户、自身价格、新进入者、市场预期
4. **逐步拟合**: 未启动→试水→拟合→成型→顶部

### 输出结构

先看哪层在涨价 → 系统变化识别 → 产业链分层 → ROE弹性排序 → 六维跟踪 → 景气阶段 → 什么说明判断错了 → 下一步验证
