苏绰——一篇文章撑起北周帝国

宇文泰能统一关陇，靠的不是刀枪，而是苏绰的一支笔。这个西魏名臣只活了四十九岁，却用一篇文章改变了中国历史的走向——六条诏书。

苏绰出身武功名门，年轻时博览群书，尤精算术。他遇到了知音宇文泰。宇文泰问他怎样治国，苏绰滔滔不绝说了一夜，宇文泰听得如痴如醉，连觉都不睡了。从此，苏绰成为西魏改革的总设计师。

六条诏书是苏绰政治思想的精华：先修心、敦教化、尽地利、擢贤良、恤狱讼、均赋役。每一条都直指社会痼疾。他提出选官不看门第看能力，这在门阀林立的南北朝是平地惊雷。他还改革了赋税制度和府兵制，为后来的北周统一奠定了根基。

苏绰死时，宇文泰悲痛欲绝，亲自为他撰写墓志铭，说"苏绰是我的萧何"。宇文泰还下令，六条诏书必须作为各级官员的必修课，凡不通者不得为官。

苏绰的影响远不止于西魏。他的治国理念通过宇文氏传到隋唐。隋文帝的开皇之治、唐太宗的贞观之治，骨子里都有苏绰的影子。这个短命的天才，用生命最后几年的火花，点亮了一个时代的曙光。
