## 📖 文章正文

最近 AI 圈最大的瓜：Claude 4.8 被用户集体吐槽"变笨了"。

不是错觉，是实锤。三个关键信号：

### 信号一：用户体感崩塌

Reddit 和 Twitter 上大量用户反映 Claude 4.8 质量下降：
- **代码生成退化**：之前一次过写 500 行代码无错误，现在要反复修 3-4 轮
- **逻辑推理变弱**：多步推理任务准确率明显下降，出现"自相矛盾"的回答
- **长篇内容胡言乱语**：超过 2000 token 的输出开始偏离主题、重复啰嗦

有用户做了 AB 测试：同一段 prompt，Claude 4.7 输出质量明显高于 4.8，差异肉眼可见。

### 信号二：基准测试被 GPT-5 反超

在关键编程基准测试上，GPT-5 已经全面反超：

| 基准测试 | Claude 4.8 | GPT-5 | 差距 |
|----------|-----------|-------|------|
| SWE-bench Verified | 58.2% | 63.7% | -5.5% |
| HumanEval+ | 86.4% | 91.2% | -4.8% |
| LiveCodeBench | 54.1% | 61.8% | -7.7% |

半年前 Claude 还是编程绝对王者，现在位置已经互换。

### 信号三：可能的原因

社区主要有三种猜测：

1. **成本优化**：Anthropic 可能在用更小的模型路由替代主力模型，降低推理成本
2. **量化压缩**：为提升响应速度做了过度量化，牺牲了模型精度
3. **Safety filter 过度拦截**：4.8 新增的安全机制过于激进，误杀大量正常输出

### 影响分析

- **用户流失**：重度用户开始回流 GPT-5，尤其编程场景
- **Claude Code 用户最受伤**：订阅 Claude Pro 的开发者感觉最明显
- **信任度下降**：Anthropic 尚未正面回应此问题，社区不满加剧

一句话：AI 赛道的竞争没有永远的王者。今天你领先，明天可能就被反超。
