百年孤独角色卡：梅梅

梅梅（蕾娜塔·蕾梅黛丝），费尔南达唯一的女儿，布恩迪亚家最听话的孩子——直到她遇见了马乌里肖·巴比洛尼亚。

她是费尔南达的骄傲，会弹钢琴，懂礼仪，像个真正的淑女。但费尔南达不知道，梅梅每晚都溜出房间，跟香蕉公司的技工约会。马乌里肖是个穷小子，身上总沾着机油味，但他让梅梅第一次笑了。

他们约好每晚在浴室见面。马乌里肖掀开屋顶的瓦片翻进来，梅梅在下面等着他。爱情来得轰轰烈烈，梅梅从听话的乖乖女变成了会撒谎的人。

费尔南达发现了。她没有声张，而是叫来了守卫埋伏。那天晚上马乌里肖刚掀开瓦片，子弹就打了过来。他摔下来，脊椎被打断，从此瘫痪在床，靠着对梅梅的思念活了一辈子。

费尔南达连夜把梅梅送进了千里之外的修道院。梅梅没有哭，没有闹，也没有求饶。她只是再也不说话了。不说话不是因为哑了——是再也不想跟这个世界说话了。她在修道院里一直活到老死，一个字都没说过。

马乌里肖死的那天，远方的梅梅似乎感觉到了什么，翻了个身，继续沉默。
