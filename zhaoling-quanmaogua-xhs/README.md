昭陵六骏-拳毛騧：身中九箭还不死的怪马

全世界大概找不到第二匹像拳毛騧这样的马——身中九箭，前胸六箭、后背三箭，还能驮着人杀出重围。打完之后才发现，它身上九个箭孔，跟筛子似的。

拳毛騧是一匹浅黄色的马，浑身鬃毛卷曲，长相奇特。"騧"字本身说的就是黄身黑嘴的马。这匹马来自突厥，是突厥可汗送给李世民的礼物。"拳毛"其实是突厥语"Kumal"的音译，意思是毛色特别的马。

拳毛騧参加的是洺水之战，对手是刘黑闼。刘黑闼是窦建德的旧部，在河北掀起了反唐大潮。李世民率军和刘黑闼在洺水决战，双方的部队在泥泞的河滩上厮杀。拳毛騧驮着李世民左冲右突，被九箭射中，仍然坚持到了战斗结束。

战斗结束后，李世民发现拳毛騧身上全是箭孔。他一数，九支。李世民当场就哭了。箭一支一支地取出来，血流了一地。

拳毛騧也在那场战斗后不久因伤势过重而死。

李世民在赞语里写道："月精按辔，天驷横行。"意思是像月亮一样纯净的战马。拳毛騧的浮雕上，九处箭孔清晰可见。今天在宾夕法尼亚大学博物馆里，依然能看到这九个洞。每一箭都是一场战斗的见证。

拳毛騧的故事告诉我们：真正的猛士，不是不受伤，而是受伤了还能咬牙坚持到最后。
