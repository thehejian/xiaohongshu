昭陵六骏-青骓

昭陵六骏-青骓：虎牢关上一道闪电

虎牢关前，窦建德十万大军列阵二十里，旌旗蔽日。李世民率三千五百玄甲军迎战。他知道，想赢只有一个办法——快。

青骓就是为"快"而生的。

青骓是一匹苍白杂色的马，浑身白中间杂着青黑色。它的名字"骓"字本来就是毛色苍白的意思。青骓是李世民手上最快的战马，没有之一。

李世民想出了一个大胆的战术。他亲率少量骑兵出阵挑战，吸引窦建德全军追击。青骓在阵前飞奔，快得像一道白色的闪电。窦建德的士兵追不上，阵型被拉成了一条长线。

就在这时，李世民突然调转马头，举起长槊大喊一声。青骓如离弦之箭，载着李世民直冲向窦建德的中军大帐。身后的玄甲铁骑顺势排山倒海般冲来。窦建德被俘，河北平定。

这一战，青骓身中五箭——前胸四箭，背后一箭。箭插在它身上，它仍然飞驰。

李世民摸着青骓的伤口说："足轻电影，神发天机，策兹飞练，定我戎衣。"意思是你的腿比影子还轻快，像飞驰的白绢一样。你帮我平定了天下，我却让你中了五箭。

青骓的浮雕是所有六骏中最有动感的——四蹄腾空，尾巴飞扬，像在云端上奔跑。看它一眼就能感受到那种驰骋的速度感。如果大唐有跑车，青骓就是法拉利。
