## 十国富庶排行榜吴越最有钱

第三名：闽国。王审知开发福建，福州泉州成为重要港口。闽国靠海上贸易发家，茶叶陶瓷丝绸出口海外。但王审知死后儿孙内斗，二十多年换了六个皇帝，钱全耗在内战上。

第二名：南唐。十国里地盘最大、文化最盛。李昪开创时国库充实，到李煜时虽然快亡国了，但金陵城的繁华冠绝江南。南唐的丝绸和盐铁是核心产业，还垄断了江南的漕运。可惜后主李煜把精力全放在写词上了。

第一名：吴越国。钱镠和继任者坚持"善事中原、保境安民"的政策，杭州成了江南经济中心。吴越修海塘、疏西湖、发展丝织和瓷器，而且没有大规模战争破坏。到钱弘俶纳土归宋时，吴越的府库比北宋朝廷还充实。赵匡胤说：钱家是真有钱。

南平夹在中间做倒爷靠收过路费，南汉靠广州的海外贸易也很有钱。十国虽然小，但比五代中原活得滋润多了。
