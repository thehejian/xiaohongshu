## 黄袍加身不是赵匡胤原创

公元950年，后汉隐帝刘承祐杀功臣，逼反了节度使郭威。郭威带兵南下，走到澶州时，士兵哗变。将士们扯下一面黄旗披在郭威身上，高呼万岁。郭威就这么"被逼"当了皇帝，建立后周。

十年后，同样的剧本重演。赵匡胤率军北上御敌，走到陈桥驿。弟弟赵光义和谋士赵普暗中操作，将士们把一件黄袍披到赵匡胤身上。赵匡胤也是"被逼无奈"——台词都跟郭威一模一样。

其实五代兵变套路非常固定。第一步：皇帝猜忌杀功臣。第二步：领兵在外的将领被逼反。第三步：走到半路士兵哗变，强行拥立。第四步：新皇帝承诺回京后赏赐，士兵卖命。第五步：进城取代旧皇帝。

后唐明宗李嗣源、后唐末帝李从珂、后周太祖郭威、宋太祖赵匡胤——全是这个模板。区别只是在哪一站哗变、披的是黄旗还是黄袍。

五代说白了就是兵变的时代。谁掌握了禁军，谁就能当皇帝。
