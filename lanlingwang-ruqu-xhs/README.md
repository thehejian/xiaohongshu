兰陵王入阵曲——中国最古老的面具舞

战场上出现了一个戴着狰狞面具的将军。身后的士兵齐声高歌，战鼓如雷。这是真实的历史——兰陵王高长恭和他的《兰陵王入阵曲》。

高长恭长得太过俊美，战场上没有威慑力。于是他戴着凶恶面具上阵。邙山之战，他率五百骑兵杀入北周大军，一直杀到洛阳城下。守军认出他的旗号，打开城门接应。这就是"邙山大捷"。

北齐人创作了《兰陵王入阵曲》纪念这次胜利。这是中国最早有明确记载的面具舞。后来传入日本，成为日本雅乐的重要组成部分。日本奈良正仓院至今保存着唐代传去的乐谱和面具。

兰陵王本人的结局很悲惨。北齐后主高纬赐他毒酒。他死前说："我忠心事主，何罪至此？"三十二岁，饮鸩而亡。面具背后的俊美面孔，终究没能躲过权力的毒箭。
