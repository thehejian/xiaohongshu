李调元——终生不剃发的秦腔始祖

清朝入关后推行剃发令——留头不留发，留发不留头。但有一个人终生不剃发，还开创了影响几百年的艺术形式——秦腔。

李调元是陕西渭南人，明末秀才。1645年清军攻占陕西，他逃入终南山。被抓后清军逼他剃发，他说"头发是父母给的"，闭眼等死。清军军官被他的勇气打动，放了他。

他逃到汉中靠卖唱为生，把陕甘一带的民间小调融合成一种新唱腔——秦腔。高亢激越，有黄土高原特有的苍凉感。他不剃发在戏台上特别显眼，观众看到明朝发型的老人唱悲壮曲子，很多人都哭了。

活到九十岁，到死都是明朝衣冠。秦腔后来传遍大西北，成为京剧的重要来源。很少有人知道这个艺术形式的开创者，是一个终生不剃发的老秀才。
